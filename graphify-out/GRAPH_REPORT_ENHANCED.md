## 1. 项目概览

### 1.1 基本信息

| 属性 | 值 |
|------|-----|
| **项目名称** | SiYuan (思源笔记) |
| **定位** | 隐私优先、自托管、完全开源的个人知识管理软件 |
| **核心功能** | 块级引用、双向链接、数据库表格、PDF 标注、AI 写作 |

| **代码规模** | ~250 万词 |
| **Stars** | 43.9k+ |

### 1.2 项目特点

SiYuan 是一款国产开源笔记工具，采用**块级架构**理念，比传统文件级笔记更细粒度。主要特点：

- **块级引用**: 细粒度内容块引用，重构思维组织方式
- **隐私优先**: 本地优先存储，数据完全自主控制
- **自托管**: 支持 Docker 部署，可通过 Web 访问
- **跨平台**: Windows/macOS/Linux + Android/iOS/HarmonyOS
- **完全开源**: UI、内核、移动端、剪藏扩展全部开放

## 3. 核心模块分析

### 3.1 块树管理系统 (Block Tree)

**路径**: `kernel/model/`

SiYuan 的核心创新是**块级架构**，每个段落、列表项、代码块都是独立的"块"：

```go
// 块结构示例
type Block struct {
    ID       string // 唯一 ID (时间戳生成)
    Type     string // 块类型 (p/h1/h2/code/list...)
    Content  string // 内容 (Markdown)
    ParentID string // 父块 ID
    RootID   string // 所在文档 ID
}
```

**核心功能**:
- 块的增删改查
- 块与块之间的层级关系
- 块的类型转换
- 块的属性扩展

### 3.2 属性视图系统 (Attribute View)

**路径**: `kernel/av/`

类似 Notion 的数据库功能，但基于块实现：

| 功能 | 说明 |
|------|------|
| **表格视图** | 类 Excel 的表格编辑 |
| **看板视图** | Kanban 卡片管理 |
| **画廊视图** | 图片卡片展示 |
| **日历视图** | 时间线管理 |
| **关系字段** | 块与块之间的关联 |

### 3.3 双向链接系统 (Backlink)

**路径**: `kernel/model/backlink.go`

实现双向链接的核心模块：

- **正向链接**: `[[块ID]]` 引用其他块
- **反向链接**: 自动记录哪些块引用了当前块
- **提及检测**: 发现文本中提到的但未链接的块
- **图谱视图**: 可视化展示块之间的关系

### 3.4 内容索引系统 (Lute)

**路径**: `kernel/lute/`

自研的 Markdown 引擎：

- **Markdown 解析**: 支持标准 Markdown + 扩展语法
- **块转换**: Markdown ↔ 块树的转换
- **搜索索引**: 全文搜索引擎
- **语法高亮**: 代码块高亮

### 3.5 编辑器前端 (Editor)

**路径**: `app/src/protyle/`

基于 ProseMirror 的富文本编辑器：

- **所见即所得**: 实时渲染 Markdown
- **块操作**: 块的拖拽、复制、删除
- **多媒体**: 图片、视频、PDF 嵌入
- **协作**: 光标同步、冲突解决

### 3.6 同步系统 (Sync)

**路径**: `kernel/model/sync.go`

支持多种同步方式：

```go
// 同步配置
type SyncConfig struct {
    Provider string // s3/webdav/aliyun
    Endpoint string
    Bucket   string
    Key      string
    Secret   string
}
```

**同步策略**:
- 数据加密后上传
- 增量同步，只传输变更
- 冲突检测与解决
- 多设备同步状态管理

### 3.7 AI 集成系统

**路径**: `kernel/ai/`

支持多种 AI 提供商：

| 提供商 | 功能 |
|--------|------|
| **OpenAI** | GPT 系列对话 |
| **Ollama** | 本地 LLM |
| **DeepSeek** | 国产大模型 |
| **智谱 AI** | ChatGLM 系列 |

**AI 功能**:
- 续写/润色/翻译
- 问答对话
- 生成闪卡

## 4. 关键设计模式

### 4.1 块级架构模式

```
传统文件级笔记:          SiYuan 块级笔记:

文档 A.md                文档 A (容器)
├── 标题                  ├── 块 1 (标题)
├── 段落 1                ├── 块 2 (段落)
├── 段落 2                ├── 块 3 (段落)
└── 列表                  ├── 块 4 (列表)
    ├── 项 1              │   ├── 块 5 (项)
    └── 项 2              │   └── 块 6 (项)
                          └── 块 7 (代码块)
```

**优势**:
- 更细粒度的引用
- 灵活的重组
- 精准的历史记录

### 4.2 双向链接模式

```go
// 链接关系存储
type Ref struct {
    DefBlockID string // 被引用块 ID
    RefBlockID string // 引用块 ID
    RefText    string // 引用文本
}

// 查询反向链接
func GetBacklinks(blockID string) []Ref {
    return queryRefs("def_block_id = ?", blockID)
}
```

### 4.3 事件驱动架构

**路径**: `kernel/eventbus/`

```go
// 事件总线
type EventBus struct {
    subscribers map[string][]Handler
}

func (eb *EventBus) Publish(event Event) {
    for _, handler := range eb.subscribers[event.Type] {
        handler(event)
    }
}
```

**事件类型**:
- 块变更事件
- 文档变更事件
- 索引更新事件
